# -feb-web.ru-
Парсер с сайта feb-web.ru про советских писателей по параметрам.

Парсер выгружает данные о советских писателей из Краткой литературной энциклопедии (КЛЭ) https://feb-web.ru

Из энциклопедии парсер выгружает только советских русскоязычных писателей и выводит обязательные четыре столбца:

author_name — ФИО писателя как указано в заголовке статьи, но без запятой, ударения, и с обычной капитализацией;

birth_name оставляем пустым, заполняем в случаях когда основным именем является псевдоним и отдельно указана фамилия (фио) при рождении;

text — текст статьи целиком;

url — прямая ссылка на текст статьи.

Дополнительно из текста вынести в отдельные столбцы:

годы жизни (birth_year, death_year); 

номер тома (volume) и год издания тома (publication_year).
